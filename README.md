# PornPicks — Luxury Gallery Starter

Mobile-first static website prototype inspired by premium editorial gallery layouts, with original PornPicks branding.

## Included
- 18+ age confirmation overlay (front-end only; not robust legal age verification)
- Popular star/profile directory with search and sorting
- Profile detail modal with sample collection chips
- Collection cards, category filters, and saved favourites
- Mobile menu and responsive layout
- Report form demo (does not send reports to a server)
- No framework or build step required

## Deploy on GitHub Pages
1. Create/open your GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose your branch and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site.
